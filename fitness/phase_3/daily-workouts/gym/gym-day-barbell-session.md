# Gym Day — Barbell Maintenance Session

> Open this note whenever you train at a day-pass gym instead of the home note for that day. Barbell pattern maintenance is the whole point of gym days — **if 3 weeks pass without one, book one.**

**Before anything:** general warm-up 5–8 min (cycle/treadmill + dynamic moves) → `[[warmup-protocol]]` (same dynamics; the ladder rules below replace the KB/DB rules).

---

## If it's Monday → Upper Block (~60 min)

| # | Exercise | Warm-up ladder | Working | Rest |
|---|----------|----------------|---------|------|

| 2 | Barbell OHP | 20×5, 25×3, 30×2 | **3×5 @ 35 kg** | 2 min |
| 3 | Chest-Supported Row | 1 light set 15×10 | **3×8 @ 32.5 kg** | 90 sec |
| 4 | Face Pulls | none — back warm | **3×12 @ 20 kg** | 60 sec |
| 5 | Tricep Pushdown | none | **2×12 @ 20 kg** | 60 sec |

## Barbell rules (they never expire)

1. **One load across all working sets.** Bench 45 means 45, 45, 45 — not 47.5→45→42.5. That W8 log entry is why 45 is the starting point.
2. Warm-up sets are never logged. Ladder rests: 60–90 sec between ramp sets, then full rest before the first working set.
3. Form gates: deadlift = flat back non-negotiable (75 is earned from 70 Easy — keep the spine flat). Squat 45 = depth + brace; if set 1 is Hard and form breaks, all 3 sets stay at 45 — no dropping, no climbing.
4. Lateral raises at the gym stay **8 kg strict** — the 2 kg home version is form practice, the gate is still open.
