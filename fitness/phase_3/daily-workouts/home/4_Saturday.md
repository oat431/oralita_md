# Saturday — Full Body (Home)

Focus: Hinge power + push + rows + carries. Time: ~60 min.

**Before anything:** general warm-up 5–8 min (treadmill walk + dynamic moves) → `[[warmup-protocol]]`

> **At a day-pass gym instead?** Close this note and open `[[daily-workouts/gym/gym-day-barbell-session]]` — run the Saturday barbell block there.

---

## 1. Kettlebell Swings

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0549-UHJlbu3.gif)

- **Warm-up:** 1 light set — KB deadlift ×10 (hinge rehearsal; rest ~60 sec after)
- **Working:** 3 × 12 @ **10 kg** — rest 60–90 sec
- **Standard:** hip snap drives the bell — arms are ropes, back stays flat, no squatting the swing. Hinge gate passed at DL 70 Easy, but form still wins over reps

## 2. Dumbbell Romanian Deadlift

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/1757-gKozT8X.gif)

- **Warm-up:** none — hinge warm from swings
- **Working:** 3 × 10 @ **12.5 kg per hand** (or kettlebell 10 kg if no handles yet) — rest 90 sec
- **Standard:** flat back, shins vertical, slow 2-sec lowering, squeeze glutes at the top

## 3. Incline Push-Ups

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0493-B1EVP9F.gif)

- **Warm-up:** 1 easy set of 5–8 on an easier progression
- **Working:** 3 × 8–12 — hands elevated (chair/step) so the angle is harder than Monday's progression
- **Standard:** full ROM, body straight. Same progression for all 3 sets

## 4. Kettlebell One-Arm Row

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0541-g9AsZ8P.gif)

- **Warm-up:** none — warm from swings
- **Working:** 3 × 10/side @ **10 kg** — rest 60 sec
- **Standard:** flat back, pull to the hip, 2-sec lowering

## 5. Suitcase Carry

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/2133-qPEzJjA.gif)

- **Warm-up:** none
- **Working:** 2 × 30 sec/side @ **10 kg** (one hand — the GIF shows both hands; walk tall with one side loaded) — rest 45 sec
- **Standard:** walk tall, no leaning away from the weight — the trunk resists

## 6. Dumbbell Lateral Raises

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0334-DsgkuIt.gif)

- **Warm-up:** none — shoulders warm from swings + push
- **Working:** 2 × 15 @ **2 kg** — rest 60 sec
- **Standard:** strict — no shrug, no lean, 2-sec lowering
