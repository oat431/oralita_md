# Tracking Templates — Index

> Master designs for all tracking files. **Phase 3 live files are created from these** after the Phase 2 completion review (Sunday). Phase 2 files in `../phase_2/` stay untouched until then.

## What lives here

| Template | Fills in | Cadence | Becomes (Phase 3) |
|----------|----------|---------|--------------------|
| `daily-check-in.md` | Sleep, weight, protein, steps | Every day | Phase 3 check-in tables |
| `training-log-week.md` | Session results, all working sets | After every session | Phase 3 training log |
| `run-walk-log.md` | Minutes, distance, pace, HR per run | Every Wednesday | Phase 3 run log (marathon data) |
| `blood-pressure-log.md` | Cuff readings | Baseline week daily → then Sun + Thu | Phase 3 health log |
| `blood-panel-baseline.md` | Clinic lab results | One-time draw, retest 6 months | Phase 3 health log |
| `body-metrics.md` | BIA + tape + photos | BIA weekly, tape/photo monthly | Phase 3 body metrics |
| `food-log.md` | Thai freestyle kcal system — anchors + dish table + weekly audit | Structure daily, audit Thu | Phase 3 kcal audit |

## Why these exist

From `[[training_audit_20260820]]` — the data gaps found in Phase 2:

1. Run/walk minutes logged 0 of 4 weeks → now minutes + distance + avg HR
2. No blood pressure → cuff log added
3. No blood panel baseline → clinic template added
4. Tape = single data point → monthly schedule added
5. No photos → monthly photo log added

Food tracking is now **designed** — see `food-log.md` (Thai anchors + dish table + weekly audit). The Kcal column in `daily-check-in.md` uses its scoring bands.
