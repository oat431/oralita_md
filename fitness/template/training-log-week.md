## Logging rules (non-negotiable)

1. Working sets only. Warm-up sets don't exist in this file.
2. **One load across all working sets.** `45→40→40` is a failed attempt + improvisation, not a 3×5. (W7 squat, W7 calves, W8 bench — three strikes. Phase 3 enforces this.)
3. **Cardio row must contain real minutes.** "Easy" is not data.
4. Record actual reps and any form limitation immediately after the session.
5. Pain flag: sharp/joint/back pain → stop, write it in Notes, report at review.
