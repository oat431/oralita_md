## Progression Rules

- ✅ Complete all reps with good form → add 2.5 kg next session (barbell) or 2.5 kg when "Easy" (accessories)
- ⚠️ Miss 2+ reps on a lift → repeat same weight next session
- ❌ Miss reps two sessions in a row → drop 10% and build back up
- 🛑 Sharp pain (not muscle burn) → stop, tell me
- 🔄 **New: if deadlift form breaks (rounded back) → drop 10 kg and rebuild.** Deadlift form is non-negotiable

## Session Protocol

1. **Warm-up (5-8 min):** 5 min cycle/treadmill walk + dynamic stretches + empty bar practice for barbell lifts
2. **Barbell warm-up sets:** For every barbell lift, do 2-3 warm-up sets before the working weight:
   - Set 1: 50% of working weight × 5
   - Set 2: 70% × 3
   - Set 3: 90% × 2
   - Then: working weight × working reps
   - *These don't count toward your 3 working sets and don't need to be logged*
3. **Rest:** 2-3 min on barbell compounds, 90 sec on machine compounds, 60 sec on isolations
4. **Log everything.** Working sets only. Same weight across all working sets.
