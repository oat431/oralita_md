# Sunday — Easy Cardio + Core (Home or Gym)

> Works anywhere — treadmill at home or at the gym. Same protocol either way.

Focus: Zone 2 treadmill + core + recovery. Time: ~40 min. This is the marathon-base day.

**Before anything:** 3 min slow treadmill to start — no general warm-up needed beyond the slow start (counts inside the session).

---

## 1. Treadmill — Easy Zone 2

- **Working:** 30–40 min — brisk walk / light incline (or very light jog if HR stays low)
- **Zone:** keep HR **117–137 bpm**. Above 137 → drop the speed/incline. This is time-in-zone training, not speed training
- **Log:** minutes + distance + avg HR in `[[logs/daily/run-walk-log]]` — every session
- **Standard:** easy = easy. If Saturday's session left you sore, this is a recovery walk — that's still a valid session, log it honestly

## 2. Sit-Ups (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/3202-iQ241UP.gif)

- **Warm-up:** none — core warm from treadmill
- **Working:** 2 × 15 — rest 45 sec
- **Standard:** controlled up, no yanking on the neck

## 3. Dead Bugs

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0276-iny3m5y.gif)

- **Warm-up:** none
- **Working:** 2 × 10/side — rest 30 sec
- **Standard:** slow, lower back pressed into the mat

## 4. Plank

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0464-CosupLu.gif)

- **Warm-up:** none
- **Working:** 2 × 40 sec — rest 30 sec
- **Standard:** no sagging. *(GIF shows a twist variant — ignore the twist)*

## 5. Stretch — 5–10 min

- Hamstrings, hip flexors, glutes, chest, upper back — 30 sec per position, breathe, no bouncing
- The yoga mat's whole job
