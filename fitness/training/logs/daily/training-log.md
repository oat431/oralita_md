## Logging Rules (non-negotiable)

1. Working sets only. Warm-up sets don't exist in this file.
2. **One load across all working sets.** `40→35→35` is a failed attempt + improvisation, not a 3×5.
3. Walks log real minutes in `[[walk-log]]` — "easy" is not data.
4. Record actual reps and any form limitation immediately after the session.
5. Pain flag: sharp/joint/back pain → stop, write it in Notes, report at the Sunday review.

*W1: every working set Medium or easier. Hard = data — repeat that load next week.*
