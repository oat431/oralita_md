# Lower Body

Focus: back squat + leg accessories. Time: ~55 min. **W1 re-entry** — every set Medium or easier.

**Before anything:** general warm-up 5–8 min (walk/cycle + dynamic moves) → `[[warmup-protocol]]` (barbell ladders)

**Machine loads:** find the weight in working set 1 (RPE ≤ Medium), log the stack number, add 2.5–5 kg when all sets are clean.

---

## 1. Barbell Back Squat

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/1436-Gnfo4FM.gif)

- **Warm-up ladder:** rest 60–90 sec between ramp sets
	- 20 kg (bar) × 5
	- 25 kg × 3
- **Working:** 3 × 5 @ **30 kg** — rest 2–3 min
- **Standard:** ONE load across all 3 sets. Brace hard; thighs parallel or below.
- **Machine alternative:** sled hack squat or Smith machine squat — same 3×5, load found in set 1, if your trainer wants the pattern guided

## 2. Leg Press

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0739-10Z2DXU.gif)

- **Warm-up:** 1 light set — 25 kg × 10 (first leg machine; rest ~60 sec after)
- **Working:** 3 × 8–10 @ **find the load in set 1** (RPE ≤ Medium) — rest 90 sec
- **Standard:** controlled depth; do not lock the knees

## 3. Lever Seated Leg Curl (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0599-Zg3XY7P.gif)

- **Warm-up:** 1 light set — 15 kg × 10 (first hamstring isolation; rest 60 sec)
- **Working:** 3 × 10 @ **find the load in set 1** (RPE ≤ Medium) — rest 60 sec
- **Standard:** pad sits above the heels, knee aligned with the pivot; 2-sec lowering
- **Alternative:** lying leg curl — same sets/reps if the seated machine is taken

## 4. Lever Standing Calf Raise (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0605-ykUOVze.gif)

- **Warm-up:** 1 light set — 20 kg × 15 (rest 60 sec)
- **Working:** 3 × 15 @ **find the load in set 1** (RPE ≤ Medium) — rest 60 sec
- **Standard:** full stretch at the bottom, 1-sec pause at the top; same load across all sets
- **Alternative:** sled calf press on the leg press — same sets/reps

## 5. Plank

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0464-CosupLu.gif)

- **Warm-up:** none
- **Working:** 3 × 30 sec — rest 30 sec
- **Standard:** no sagging; record the actual time. *(GIF shows a twist variant — ignore the twist)*
