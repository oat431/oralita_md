# Upper Body

Focus: barbell bench + machine shoulder press. Time: ~60 min. **W1 re-entry** — every set Medium or easier. Hard = data, not a problem: repeat that load next week.

**Before anything:** general warm-up 5–8 min (walk/cycle + dynamic moves) → `[[warmup-protocol]]` (barbell ladders)

**Machine loads:** find the weight in working set 1 (RPE ≤ Medium), log the stack number, add 2.5–5 kg when all sets are clean.

---

## 1. Barbell Bench Press

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0025-EIeI8Vf.gif)

- **Warm-up ladder:** rest 60–90 sec between ramp sets
	- 20 kg × 5
	- 25 kg × 3
	- 30 kg × 2
- **Working:** 3 × 5 @ **32.5 kg** — rest 2–3 min
- **Standard:** bar touches chest, no bounce, same load across all working sets

## 2. Lever Shoulder Press (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0603-67n3r98.gif)

- **Warm-up:** 1 light set — 10 kg stack × 10 (first shoulder work; rest ~60 sec after)
- **Working:** 3 × 8–10 @ **find the load in set 1** (RPE ≤ Medium) — rest 90 sec
- **Standard:** seat height so handles sit at shoulder level; back flat on the pad, ribs down, no arching off the seat
- **Note:** barbell OHP returns in a later block — once the machine press is clean at ~30 kg and the trainer has seen your rack position

## 3. Lever Seated Row (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/1350-7I6LNUG.gif)

- **Warm-up:** 1 light set — 15 kg × 10 (first back exercise; rest ~60 sec after)
- **Working:** 3 × 8–10 @ **find the load in set 1** (RPE ≤ Medium) — rest 90 sec
- **Standard:** chest against the pad, shoulder blades back and down; full range, same load across sets
- **Alternative:** chest-supported row — same sets/reps if that machine is free

## 4. Face Pulls

- **Warm-up:** none — back is warm from the row
- **Working:** 3 × 12 @ **find the load in set 1** (RPE ≤ Medium, cable) — rest 60 sec
- **Standard:** pull toward forehead; finish with external rotation

## 5. Tricep Pushdown

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0241-gAwDzB3.gif)

- **Warm-up:** none — triceps worked hard in bench + shoulder press
- **Working:** 2 × 12 @ **find the load in set 1** (RPE ≤ Medium, cable) — rest 60 sec
- **Standard:** exactly 2 sets; no torso swing
