# Full Body

Focus: deadlift + front squat. Time: ~60 min. **W1 re-entry** — every set Medium or easier.

**Before anything:** general warm-up 5–8 min (walk/cycle + dynamic moves) → `[[warmup-protocol]]` (barbell ladders)

**Machine loads:** find the weight in working set 1 (RPE ≤ Medium), log the stack number, add 2.5–5 kg when all sets are clean.

---

## 1. Barbell Deadlift (conventional)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0032-ila4NZS.gif)

- **Warm-up ladder:** rest 60–90 sec between ramp sets
	- 30 kg × 5
	- 40 kg × 3
- **Working:** 1 × 5 @ **50 kg** — one work set only
- **Standard:** flat back is non-negotiable; if form breaks, drop to 40 kg and report it

## 2. Barbell Front Squat

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0042-zG0zs85.gif)

- **Warm-up ladder:** rest 60–90 sec
	- 20 kg (bar) × 5
	- 25 kg × 3
- **Working:** 3 × 5 @ **27.5 kg** — rest 2 min
- **Standard:** elbows high; same load across work sets
- **Machine alternative:** sled hack squat (same sets/reps, load found in set 1) if the rack position bothers your wrists or shoulders — swap 1:1

## 3. Lat Pulldown

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/2330-LEprlgG.gif)

- **Warm-up:** 1 light set — 12.5 kg × 10 (first back exercise; rest ~60 sec after)
- **Working:** 3 × 8–10 @ **find the load in set 1** (RPE ≤ Medium) — rest 90 sec
- **Standard:** torso still; full controlled pull

## 4. Lever Incline Chest Press (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/1299-jHAnWmT.gif)

- **Warm-up:** 1 light set — 12.5 kg × 10 (first chest work; rest ~60 sec after)
- **Working:** 3 × 8–10 @ **find the load in set 1** (RPE ≤ Medium) — rest 90 sec
- **Standard:** seat height so handles sit at mid-chest; shoulder blades pinned to the pad; no bouncing out of the bottom

## 5. Lever Leg Extension (machine)

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0585-my33uHU.gif)

- **Warm-up:** 1 light set — 15 kg × 12 (first quad isolation; rest ~60 sec after)
- **Working:** 3 × 12 @ **find the load in set 1** (RPE ≤ Medium) — rest 60 sec
- **Standard:** knees track over toes; 2-sec lowering; no swinging or bouncing

## 6. Seated Cable Row

![form|150](https://raw.githubusercontent.com/hasaneyldrm/exercises-dataset/main/videos/0861-fUBheHs.gif)

- **Warm-up:** none — back warm from pulldown
- **Working:** 3 × 8–10 @ **find the load in set 1** (RPE ≤ Medium, cable) — rest 60 sec
- **Standard:** full range; no jerking
