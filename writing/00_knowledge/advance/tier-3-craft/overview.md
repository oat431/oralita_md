# Craft and Process — Overview

> **Tier 3** of the advanced writing reference: the skills that apply across every mode and domain, namely structure, evidence, style, clarity, process, and evaluation.

## Why These Are Cross-Cutting

A technical report and a memoir both need structure, evidence, and clarity. Only the *content* of those skills changes with the domain. Learn the craft once; apply it everywhere.
