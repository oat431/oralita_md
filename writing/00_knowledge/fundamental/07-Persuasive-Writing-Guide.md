# Persuasive Writing Guide

> Persuasive writing convinces — the reader asks **"Why should I care/agree?"** Claim, evidence, reasoning — and the counterargument taken seriously, not strawmanned. Up to parent map [[writing/00_knowledge/fundamental/00-Writing-Types]].
>
> [[01-Review-Writing-Guide]] is this family's evaluation lane (criteria → evidence → verdict). This guide covers the rest: essays, copywriting, proposals.

## What Persuasion Actually Is

Not manipulation — an argument, which means it can be evaluated and can lose. The classical triad still holds:

| Lever | What it is | Failure mode alone |
|-------|-----------|---------------------|
| **Logos** | Facts, data, logic | Correct but unpersuasive — nobody feels the stakes |
| **Ethos** | Credibility — expertise, fairness, sourcing | Trust without substance — feels hollow under scrutiny |
| **Pathos** | Emotional stakes | Moving but empty — collapses the moment someone asks for evidence |

Persuasive writing needs all three; leaning on only one is the fastest way to lose a skeptical reader. **The golden rule: represent the strongest version of the opposing view, then beat that.** Beating a weak version (strawmanning) convinces nobody who already disagreed with you.

## The Skeleton (general argumentative)

```
1. CLAIM / THESIS      — one sentence, ARGUABLE (someone could reasonably disagree)
2. STAKES               — why this matters to the reader, now
3. EVIDENCE             — per point: claim → evidence → reasoning back to the thesis
4. COUNTERARGUMENT      — the strongest opposing view, stated fairly, then rebutted
5. CONCLUSION / ASK     — what the reader should now believe or do
```

A thesis that nobody would disagree with ("exercise is good for you") isn't an argument — it's a fact wearing an essay's clothes. Test your thesis: can you write a one-paragraph honest version of someone disagreeing with it? If not, sharpen the claim.

## Type Cheat-Sheet

| Type | Structure | Where used |
|------|-----------|------------|
| Opinion / argumentative essay | Thesis → evidence → counterargument → conclusion | Op-eds, essays, position papers |
| Copywriting / ads | **AIDA**: Attention → Interest → Desire → Action | Ads, landing pages, product copy |
| Proposal / pitch | Problem → solution → why us → the ask | Business proposals, pitches, grant applications |

## AIDA in Depth (Copywriting)

- **Attention** — the headline/hook; it has one job, stop the scroll
- **Interest** — name the reader's actual problem, so they see themselves in it
- **Desire** — translate every **feature** (what it has) into a **benefit** (what it does *for them*) — features inform, benefits persuade
- **Action** — exactly **one** call to action. Two CTAs is zero CTAs; the reader defaults to neither.

## Evidence Discipline

- **Steelman before you rebut** — state the counterargument as its best believer would state it, not as a punching bag
- **Specific evidence beats general assertion** — a number, a named source, a concrete scenario
- **Pathos supports, never replaces, logos** — emotional stakes make a reader care about evidence that's already there; they can't substitute for evidence that isn't
- **One ask, clearly stated** — proposals that describe the problem for 90% of the page and bury the ask in the last line waste the reader's decision-making energy on the wrong section

## Common Failure Modes

1. **Strawmanning the counterargument** — arguing against a weak version nobody actually holds
2. **All pathos, no logos** — emotionally compelling, structurally empty; collapses under one follow-up question
3. **Feature-dumping in copy** — a spec list instead of a reason to care
4. **Multiple CTAs** — asking for three things and getting none of them
5. **Unarguable thesis** — a statement so safe it isn't actually a claim
6. **Burying the ask** — the reader finishes a proposal still unsure what's being requested

## Fill-in Template

```markdown
# <Title>

**Thesis:** <one arguable sentence>

## Why this matters now
<stakes for the reader>

## Evidence
### <Point 1>
<claim → evidence → reasoning back to thesis>

## Counterargument
<the strongest opposing view, stated fairly>
<your rebuttal>

## Conclusion / the ask
<what the reader should now believe or do — ONE thing>
```
