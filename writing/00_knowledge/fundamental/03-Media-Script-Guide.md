# Media Script Guide

> Scripts are writing whose final home is **time and performance**, not the page — every format below encodes who speaks, when, and what the audience sees. Up to parent map [[writing/00_knowledge/fundamental/00-Writing-Types]].

## The Core Skill (shared by all formats)

Whatever the medium, scripts come down to three moves:

1. **Slugline / scene header** — WHERE and WHEN: `INT. COFFEE SHOP - NIGHT` (INT./EXT., location, time)
2. **Action lines** — what we SEE and HEAR, present tense, only what a camera/mic can capture. No thoughts, no backstory ("just the facts," visually descriptive).
3. **Dialogue** — who speaks, how delivered. Extensions: `(V.O.)` voice-over, `(O.S.)` off-screen. Parentheticals like `(quietly)` sparingly — actors hate being told how to act every line.

**The one rule that shapes everything:** in standard screenplay format (12-point Courier), **one page ≈ one minute of screen time**. Format isn't cosmetic; it *is* the timing estimate the whole production runs on.

## Format 1 — Feature Screenplay

- 12pt Courier/Courier New throughout · sluglines in caps · character names capped and centered above dialogue
- Length conventions: feature ~90–110 pages; ~15 pages/act as rough ballast
- Structure: pour a story structure ([[02-Storytelling-Guide]] — Save the Cat was literally written for this) into the format above

```text
INT. APARTMENT - NIGHT

Rain hammers the window. MAYA, 30, stares at an unopened
letter, coffee gone cold beside it.

                    MAYA
          Not today.

She drops it in the drawer. Locks it.
```

## Format 2 — TV Episode

- Cold open (teaser) → title card → Acts (usually 4–5 for hour-long, 2–3 for sitcoms) → tag
- **Act breaks land on mini-cliffhangers or reversals** — that's where ads go, so each act must end wanting to know more
- A-plot (main story) + B-plot (usually thematic counterpoint) + sometimes C-runner
- Episodic engine: Dan Harmon's Story Circle per episode, run per-character for ensembles ([[02-Storytelling-Guide]])

## Format 3 — AV Script (commercials, shorts)

Two columns, one line per shot:

| VIDEO | AUDIO |
|-------|-------|
| Close-up: hand slams alarm clock, 6:59 | SFX: harsh buzz cuts to silence |
| Whip-pan to face, eyes snap open | VO: "Mornings shouldn't start like this." |
| Product hero shot on desk | MUSIC: upbeat sting · VO: "There's a better way." |

Keep total words ≈ runtime: ~150 words ≈ :60, ~75 ≈ :30. Every line = one camera event.

## Format 4 — YouTube / Video Essay

Not a screenplay — an outline built for **retention**:

```
0:00–0:15   HOOK      — the most surprising claim/clip first; never "hey guys welcome back"
0:15–0:45   SETUP     — what the viewer will get + why it matters (stakes)
BODY        SECTIONS  — each = claim → evidence → payoff; re-hook between sections
                      — pattern interrupts: B-roll change, zoom, joke, graphic
ENDING      PAYOFF    — deliver the promised insight, then ONE call to action
```

Write as two layers: **spoken-word script** (what you say, conversational) + **shot notes** (B-roll, on-screen text, graphics per section). Retention beats matter more than prose beauty — viewers leave at boring moments, not bad ones. For explainers/reviews, borrow the expository spine from [[writing/00_knowledge/fundamental/00-Writing-Types]]; verdict-first works well (see [[01-Review-Writing-Guide]]).

## Format 5 — Podcast / Audio Drama

Visuals are gone; **sound IS the picture**:

| Cue type | Example |
|----------|---------|
| SFX | `[SFX: rain on tin roof, steady]` |
| Music | `[MUSIC: tense drone fades in under dialogue]` |
| Ambience shift | `[AMBIENCE: café murmur swells, then door chime]` |

Rules: identify speakers by name in dialogue early and often (ears can't see who's talking) · narrate movement ("watch your step — the floor's wet") since listeners can't see it · audio-drama scenes need an establishing sound within the first seconds.

## Choosing a Format

```
Story for the screen, industry-standard?     → Screenplay format
Episodic with ad breaks?                     → TV structure
Ad / promo under 90 seconds?                 → AV two-column
Talking-head explainer / review channel?     → YouTube retention outline
Ears-only storytelling?                      → Podcast/audio-drama cue script
```
