# Writing Types — Overview & Index

>

## The Foundation: Four Classical Modes

Every piece of writing ever published sits on top of one or more of these four modes. Genre labels (blog post, screenplay, review) are just containers; the mode is what the words are actually *doing*.

| Mode | Purpose | Reader asks | Signature moves |
|------|---------|-------------|-----------------|
| **Expository** | Explain / inform | "What does this mean?" | Facts, definitions, structure, no author opinion |
| **Descriptive** | Make the reader see/feel | "What is it like?" | Sensory detail, concrete nouns, show don't tell |
| **Narrative** | Tell what happened | "Then what happened?" | Character, event, sequence, cause → effect |
| **Persuasive** | Convince | "Why should I care/agree?" | Claim, evidence, reasoning, acknowledgment of counterarguments |

Key insight: **real pieces are blends.** A movie review is expository (plot facts) + descriptive (the look of it) + persuasive (the verdict). A campaign log is narrative carried by description. Knowing the modes lets you name which job each paragraph is doing — and cut paragraphs doing no job.

> The advanced reference treats **analytical, instructional, and reflective** as distinct modes (8 total). See [[00-Writing-Types-Reference]].

## The Full Map by Purpose

### 1. To explain — Expository family

| Type | What it looks like | Where you'd use it |
|------|--------------------|--------------------|
| Technical documentation | Step-by-step, commands explained | READMEs, runbooks, setup guides |
| Journalism (news report) | Inverted pyramid: conclusion → details → background | News, incident reports |
| Explainer / blog post | Question → answer, analogies, examples | Dev blogs, tutorials |
| Academic writing | Thesis → literature → method → findings | Papers, whitepapers |

→ Method and templates live in [[06-Expository-Writing-Guide]].

### 2. To tell — Narrative family

| Type | What it looks like |
|------|--------------------|
| Short story / flash fiction | One situation, compressed arc |
| Novel / novella | Multiple arcs across chapters |
| Memoir / personal essay | True events, shaped like a story, with reflection |
| Campaign log / journal | Chronological events with narrator voice (see BG3 vault) |
| Anecdote / case study | Real story serving a point |

→ Structure options live in [[02-Storytelling-Guide]].

### 3. To convince — Persuasive family

| Type | What it looks like |
|------|--------------------|
| Opinion / argumentative essay | Thesis + evidence + counterargument handling |
| Copywriting / ads | Attention → interest → desire → action |
| Reviews | Evaluation against criteria → recommendation |
| Proposals / pitches | Problem → solution → why us |

→ Method and templates live in [[07-Persuasive-Writing-Guide]].

### 4. To evaluate — Review family *(your focus)*

| Medium | Typical criteria |
|--------|------------------|
| Book | Prose, plot, characters, theme, pacing |
| Film / series | Script, direction, acting, cinematography, sound |
| Game | Gameplay loop, story, art, audio, technical state, value |
| Product / tech | Build quality, performance, price-to-value, support |
| Restaurant / travel | Food/experience, service, atmosphere, price, location |

→ Method and skeleton live in [[01-Review-Writing-Guide]].

### 5. To perform — Media scripts *(your focus)*

A script is writing whose final home is **time and performance**, not the page. The format encodes who speaks, when, and what the audience sees.

| Form | Format signature |
|------|------------------|
| Feature screenplay | 12pt Courier, sluglines, 1 page ≈ 1 minute |
| TV episode | Teaser + acts, breaks on cliffhangers |
| AV / commercial script | Two columns: VIDEO \| AUDIO |
| YouTube / video essay | Hook-first outline + retention beats + B-roll notes |
| Podcast / audio drama | Sound cues replace visuals |

→ All five formats live in [[03-Media-Script-Guide]].

### 6. To instruct a machine — Prompt family

| Type | What it looks like |
|------|--------------------|
| Everyday prompt | RTF: role → task → format |
| High-stakes prompt | CO-STAR: context, objective, style, tone, audience, response format |
| Creative prompt | CRISPE: capacity, insight, statement, personality, experiment |
| Agent profile / SOUL | The ultimate long-form prompt — persona + scope + constraints |

→ Frameworks, techniques and failure modes live in [[05-Prompt-Writing-Guide]].

## Which Type Do I Need? (decision path)

```
What is the piece's main JOB?
├─ Explain something        → expository family   → [[06-Expository-Writing-Guide]]
├─ Recount an experience    → narrative family    → [[02-Storytelling-Guide]]
│   └─ Is it true?          → memoir/log/case study lane
├─ Judge something          → review family       → [[01-Review-Writing-Guide]]
├─ Sell or convince         → persuasive/copy lane → [[07-Persuasive-Writing-Guide]]
├─ Instruct a machine       → prompt family        → [[05-Prompt-Writing-Guide]]
└─ Be performed/produced    → script family       → [[03-Media-Script-Guide]]
    └─ Screen? Audio? Both? → pick format by medium
```

## How the Three Goal Areas Connect

Your three interests are not separate skills — each is a different blend of the same four modes:

- **Review** = expository spine + persuasive verdict + just enough narrative to set scenes without spoiling.
- **Storytelling** = narrative engine + descriptive texture; persuasion sneaks in via stakes (making the audience want something).
- **Media script** = storytelling *structure* poured into a *production format*; a video essay adds an expository/persuasive spine on top.

Learn the modes once, and every new format is just a new container.
