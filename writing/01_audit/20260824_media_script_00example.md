# Audit — `media_script/00_example` (รีวิว วิมานหนาม, YouTube)

> Audited 2026-08-24 against [[03-Media-Script-Guide]]. Contract: problems first · cited evidence · `[objective]` vs `[taste]`.

## Summary Judgment

This is `writing/review/00_example` typed into a script-shaped box, not a script. The content is the same — same praise, same beats, even the same closing "10/10" — but none of it was rebuilt for a medium where **sound and image do half the work.** Right now a video editor handed this file has nothing to cut to: it's one unbroken paragraph of talking. Fixing it isn't a rewrite, it's addition — a visual layer this draft never grew.

## Problems (cited)

1. **[objective] Banned hook, verbatim.** The guide's Format 4 section says hook-first, "never 'hey guys welcome back.'" This script's first line *is* that exact pattern. The real hook — "ผมไปดูเพราะผู้กำกับภาพ" — is sitting three paragraphs later, doing nothing.
2. **[objective] No visual layer at all.** A video essay's whole advantage over a written review is pattern interrupts — B-roll, zoom, on-screen text — keeping a wandering viewer's attention. This draft has none; as written it would play as a static talking-head monologue for its full runtime, which the guide flags as exactly where viewers leave.
3. **[objective] CTA overload.** "กดไลค์ กดแชร์ กดซับสไครบ์ กดกระดิ่ง...ดูคลิปถัดไป" is five asks in one breath. The template's own law: ONE call to action, never more — five asks functions as zero.
4. **[objective] No weaknesses / one-sided verdict.** Same defect the review audit (`20260823_review_00example`) already flagged in the source piece — carried forward unchanged into the script. Worth fixing once at the writing-habit level, not per format.
5. **[objective] Missing spoiler line.** Same gap the review audit flagged, still present here — the guide names this as its own checklist item and it didn't survive the format conversion either.
6. **[taste] Feels transcribed, not shot.** Every strong image in the source review — the frame-as-wallpaper cinematography, the cast's greed dynamic — never gets a corresponding shot note. A director's-eye pass would ask "what do we cut to" for each of those lines; none currently has an answer.

## What Works

- **The substance survived the format jump.** The specific praise (production design selling the greed, the frame-worthy cinematography, the earworm needle-drop) is still there and still concrete — it's a placement and packaging problem, not a content problem.
- **The director-first framing is a real hook** — "I only went because of the cinematographer" is a genuinely strong, specific reason to watch. It's just buried where the throwaway greeting should have been cut instead.

## Fix Priority (next draft)

1. Delete the greeting; open cold on the director-hook line — that's the actual 0:00–0:15
2. Add a shot-notes column or bracketed cue at every beat — start with one visual per paragraph
3. Cut the ending to one CTA
4. Add a spoiler line before the premise paragraph
5. Add one honest weakness before the score — this is now the second format where this piece has shipped without one
