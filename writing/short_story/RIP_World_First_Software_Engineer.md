# Rest In Peace Margaret Hamilton

> แหล่งข่าว: [Margaret Hamilton, computing pioneer who led software development for the Apollo program, dies at 90 — MIT News](https://news.mit.edu/2026/margaret-hamilton-computing-pioneer-dies-1007)

ผมตื่นมาทานอาหารเช้าก่อนไปทำงานแล้วได้อ่านข่าวว่า คุณ Margaret Hamilton ได้เสียชีวิตในวัย 90 ปี ข่าวนี้ค่อนข้างสะเทือนใจผมครับ แต่ก็ดีใจที่ทุกวันนี้ได้ทำอาชีพเดียวกับเขา

ย้อนตอนผมอยู่ปีหนึ่ง ผมได้เรียนวิชา Intro to Software Engineering ตอนเรียนก็ทึ่งไปว่า คนเราคิดกระบวนการสร้างอะไรที่จับต้องไม่ได้เป็นขั้นเป็นตอนแบบนี้ได้ยังไง จนปีสามที่ได้เรียนลึกในทุกขั้นตอนการทำ software อยู่ ๆ ผมก็นึกสงสัยว่าใครเป็น Software Engineer คนแรกของโลก แล้วเขาทำ project อะไรในตอนนั้น 

ผมไปเจอ Margaret Hamilton และ โครงการ Apollo 11 software ที่ส่งคนไปดวงจันทร์คือ project ที่เธอคุมงาน 

ในยุค 1960s การเขียน program เป็นอะไรที่ยากมาก ๆ ยิ่งการทำงานเป็นทีมคือนรกแตกเพราะมันไม่มีมาตรฐานใด ๆ สิ่งที่คุณ Margaret ทำคือการผลักดันให้การ develop software ถูกยอมรับว่าเป็น Engineering และวางรากฐานของ software engineering

ยุคนั้นการเขียนโปรแกรมคือการเจาะรูบนบัตร แต่จะให้มันทำงานบนยานได้ ต้องแปลงโปรแกรมจากบัตรเจาะรูไปเป็นสายไฟ และให้ทีมงานค่อย ๆ ถักสายไปเป็นคำสั่งบนยาน กว่าจะเสร็จหนึ่งชุดใช้เวลาพอสมควร (8 อาทิตย์ต่อ 1 แผง)

โครงการ Apollo 11 ไม่ได้ราบรื่น ก่อนลงจอด เรดาร์มีปัญหา แต่เพราะ software ที่เธอสร้างมี failsafe สามารถทิ้งงานที่ไม่จำเป็นแล้ว focus การจอดลงดวงจันทร์ และในที่สุดเราก็พาคนไปเหยียบดวงจันทร์ได้

เธอเป็นหนึ่งใน Pioneer ของสายอาชีพ Software Engineering สร้างแรงบันดาลใจให้มนุษย์สร้างสิ่งเจ๋ง ๆ ใน Cyberspace 

และบัดนี้ เธอได้เป็นหนึ่งเดียวกับจักรวาลไปแล้ว 
ขอส่งวิญญาณเธอในฐานะ Software Engineer รุ่นเหลนของเธอครับ

กลับคืนสู่จักรวาล กลับคืนสู่ดวงจันทร์ ขอบคุณที่ทำให้ Software Engineering ถูกยอมรับเป็นศาสตร์วิศวกรรมบนโลกใบนี้
