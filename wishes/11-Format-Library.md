# 🎴 11: Format Library

> Companion to [[01-Luck-Wishes]] through [[10-Journey-Wishes]]. Parent map: [[wishes/00_overview]]. This file adds **no new phrases**: it is the delivery layer for the verified library. A format never changes a snippet's provenance; the labels (attested / modern / `[craft]`) travel with the words.

**Format tags:** 💬 chat send · 🃏 rune card · 🏮 write & hang · 🕯️ blow & burn · 🪙 toss · 📜 charm inscription · 🎋 draw & cast

## The two layers

| Layer | Lives in | Owns |
|---|---|---|
| Content | [[01-Luck-Wishes]] … [[10-Journey-Wishes]] | the words, the sources, the register flags |
| Delivery | this file | the shape of the send: medium, order, length, where the source line goes |

Rule zero: **the paste is pure.** A fenced block from any type file is the whole message. Translits, EN glosses, citations, and ⚠️ notes stay in the vault, never in the paste.

## Format 0: 💬 the chat send (the library's home)

The default format, and the one every type file was built for.

**The Three-Line Send** (the house recipe, used by every assembled example in 01–10):
1. one **ancient line** (verified, from the occasion's section)
2. one **Thai or English line** (the recipient's everyday register)
3. one **`[craft]` closer** (the modern send-off that lands it)

Worked example (a send-off, from [[10-Journey-Wishes]]):

```
Heill þú farir! Heill þú aftr komir!
ขอให้เดินทางราบรื่นนะ
Go well, and take the good weather with you.
```

Rules: one register per message (see each file's Misuse Notes); zero or one emoji, never a row; keep any single quoted passage short (the blocks are already curated); never merge two sources into one body line.

## Format 1: 🃏 the rune card

A physical card or a single image: one rune, one line.

**Spec:** front = the rune glyph, centered, plus the wish line in its original script (Latin letters for the rune poems); back = translit, EN, source, and the attested-vs-modern label. One rune per card. No extra ornament.

Card front example ([[10-Journey-Wishes]]):

```
ᚱ
Rad byþ on recyde rinca gehwylcum
sefte ond swiþhwæt, ðamðe sitteþ on ufan
meare mægenheardum ofer milþaþas.
```

More cards: ᚠ Fehu ([[04-Prosperity-Wishes]]), ᛟ Eþel ([[09-Family-Wishes]]), ᛞ Dagaz ([[06-New-Beginnings-Wishes]]).
⚠️ The front keeps the old spelling exactly; the back carries the honesty.

## Format 2: 🏮 write & hang

- **Ema plaque:** one line plus a name/date on the back; write the line only, no source. (Ema are the wooden wish plaques hung at Japanese shrines: the overview's mechanism inventory.)
- **Sky lantern (Yi Peng, Lanna Thailand):** one wish per lantern, a short line plus the sender's name. ⚠️ Practical note: many places regulate or ban lantern releases (fire and aviation risk), so check local rules before promising this format.
- **Loi krathong float (Thailand):** one line spoken as the float leaves the hand; quiet register pairs well with [[07-Peace-Wishes]].
- **Red ribbon on a tree:** a tag with one line (the Chinese wish-ribbon custom in the overview inventory).

Rule: these formats carry **one** line, twelve words or fewer. The line must stand alone, because there is no source line on a lantern.

## Format 3: 🕯️ blow & burn

Spoken, not written. **Candle:** say the line, then blow. **Dandelion:** say it, then blow the seeds.

The birthday script ([[08-Dream-Wishes]] + [[09-Family-Wishes]]):

```
ขอให้คำอธิษฐานเป็นจริงนะ
May the candle hear you, and the year agree.
```

Rule: one or two lines, second person, present tense. Never a lineage or fertility line unless the wish is explicitly wanted (see 09's 🚩 flags).

## Format 4: 🪙 toss

Say the line **as the coin leaves the hand**: one line, no explanation, then walk away. The classic mechanisms (wishing wells and fountains) are in the overview's inventory.
Pairing: [[01-Luck-Wishes]] for luck, [[08-Dream-Wishes]] for big hopes. Quiet register: no punchlines.

## Format 5: 📜 charm inscription (wear & carry)

For engraved objects, printed amulet cards, or phone-wallpaper inscriptions: **the object carries the line only**; the source note lives in the vault (it is already in the type file's sources section, never on the object).
Length: ten words or fewer. The Købelev precedent ([[05-Protection-Wishes]]) is the model: a line that says what it is, e.g. `This is a hammer. Let it be enough.` `[craft]`
⚠️ Living traditions are not DIY formats: Sak Yant, phra khrueang, and sai sin belong to their traditions' rules and practitioners (see 05's culture notes). Gift respectfully, never imitate.

## Format 6: 🎋 draw & cast

- **The library deck:** ten suits (the ten type files), six languages. Draw one card per send; the draw can be literal (printed cards) or a random pick from the folder.
- **Omikuji slip:** a fortune slip with the line printed on it; the traditional move for an unlucky draw is to tie the slip to a tree and leave it behind (the overview's omikuji inventory).
- **Rune draw:** cast one rune from the Elder Futhark set and read its **name-word** as the wish's anchor. ⚠️ The rune poems are word-entries, not fortunes: keep the modern "meaning" labels on (see [[06-New-Beginnings-Wishes]] and [[09-Family-Wishes]]).
- **The pull ritual (gacha):** the Viking Rune Wish recipe in [[01-Luck-Wishes]] is the documented player-folklore format: say the line, make the pull, no promises.

## Anti-patterns

- **Source lines in the paste.** The fastest way to turn a wish into a lecture. The fenced blocks exist for a reason.
- **Mixing registers.** A condolence line next to a gacha joke; a fertility wish to someone who never asked. See each file's ⚠️ list.
- **Stacking files.** Two ancient languages, three Thai lines, two crafts: that is a collage, not a wish. One to three lines.
- **Dropping the labels.** A modern esoteric reading sold as Viking-age fact; a "traditional prayer" cited to a scripture it is not in. The labels are the library's spine.
- **Promising outcomes.** "May the runes favor you," never "this gets you the 5-star."
- **DIY living traditions.** Sak Yant, amulets, and sai sin are practiced traditions with rules; this library borrows respect, not ink.
