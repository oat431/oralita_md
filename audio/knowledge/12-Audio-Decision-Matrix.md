# Audio Decision Matrix

Use this before buying. Ask what problem the item solves, whether the problem is measurable or audible, and whether your current gear already solves it.

## Priority matrix

| Item/value | Usually worth attention? | Why |
|---|---:|---|
| Proper IEM seal and comfort | **High** | Directly changes bass, isolation, comfort, and safe volume |
| Eartip size/style | **High** | Cheap way to change seal and fit |
| EQ | **High** | Directly changes tonal balance; reversible and inexpensive |
| Low gain and safe volume | **High** | Protects hearing and reduces hiss/accidental loudness |
| Reliable USB data cable | **High** | Prevents disconnects and dropouts |
| Low output impedance | **High** | Avoids unwanted interaction with IEM impedance |
| Low noise floor | **High** | Important with sensitive IEMs |
| DAC/amp with enough clean power | **High when needed** | Solves clipping or insufficient volume |
| Source/app stability | **High** | Daily reliability matters more than theoretical capability |
| Measured channel matching | **Medium–high** | Prevents image shifting |
| TIDAL lossless tier | **Medium** | Avoids lossy encoding; mastering still matters |
| Volume normalization | Preference | Useful for playlist consistency; off for mastering comparison |
| Crossfade | Preference | Convenient, but changes album transitions |
| Dolby/spatial DSP | Preference/use-case | Useful for films/games if preferred; not automatically hi-fi |
| Balanced output | Conditional | Useful for power, noise, or connector needs—not magic |
| Higher sample-rate badge | Usually low | Does not guarantee audible improvement |
| More driver count | Low | Does not guarantee better tuning |
| Exotic cable metal | Very low | Little reason without a measurable electrical issue |
| Audiophile USB cable | Very low | Digital connection either transfers correctly or has errors |
| Cable burn-in | Very low | No established mechanism for the claimed improvement |
| Audiophile fuse/power accessory | Very low | Not a rational priority for this portable chain |

## Hardware decision tree

### Is it too quiet or clipping?

- Confirm the MX1 is selected.
- Use low gain first, then high gain only if necessary.
- If the D1 already reaches comfortable loudness, more amplifier power is unnecessary.

### Is there hiss?

- Lower the gain.
- Lower the source's analog/digital gain if applicable.
- Check another source or IEM.
- Investigate the DAC/amp noise floor before buying accessories.

### Is bass weak?

- Check the eartip seal and insertion.
- Try another tip size.
- Only then try a low-shelf EQ boost.

### Is the sound too bright or tiring?

- Reduce volume.
- Check the seal and tips.
- Try a gentle high-shelf/peak cut.
- Test for 20–30 minutes before judging.

### Are there dropouts?

- Replace the USB-C data cable.
- Reconnect and re-authorize USB permission.
- Check phone battery/power behavior.
- Increase UAPP buffer if needed.
- Do not blame the DAC's sound quality for a data/connection problem.

## Value rule

Before spending money, write:

```text
Problem:
Evidence:
Current gear that might solve it:
Cheapest reversible test:
What result would justify buying:
```

If there is no clearly stated problem, keep listening. “More expensive” is not a problem description.
