# Body Metrics — Weekly / Monthly Template

> Sunday morning, fasted, after bathroom. One standardized reading per week — daily BIA readings are noise. Scale (weekly) + tape (monthly) + photos (monthly) live in this one file because they all happen in one Sunday-morning sitting.

## A. Body Composition (smart scale — every Sunday)

| Week | Date | Weight (kg) | Fat (kg) | Fat % | Muscle (kg) | Visceral Fat | Body Water % | Waist-to-Hip |
| ---- | ---- | ----------- | -------- | ----- | ----------- | ------------ | ------------ | ------------ |
|      |      |             |          |       |             |              |              |              |

**Reading rules**

- Muscle: preserve ≥75 kg. Downward acceleration = protein/deficit problem, not bad luck.
- Visceral: 21 now, target <15 next, <10 long-term.
- Water: >48% = trustworthy readings. <45% = dehydrated, BF% unreliable.

## B. Tape Measurements (monthly — 1st Sunday of month)
