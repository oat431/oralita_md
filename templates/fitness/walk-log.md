# Walk Log — Template

> The fat-loss cardio runs on this file. One row per **walk session**. Fill immediately after the walk while the watch still has the workout on screen. (Marathon dropped 2026-10-24 — walking is the cardio, no run progression.)

## Frequency

- **W1 dose: 3 walks/wk (Tue/Thu/Sat).** Daily walking is allowed from W2 only with zero foot complaints — add one day at a time, cap 60 min.
- Tue/Thu: 40–50 min brisk. Sat: 5.2 km condo→Esplanade route (~55–65 min).
- Strength days = MRT. The walk is a session, not a commute.

## How to get the numbers (Xiaomi Watch S4)

1. Start a **Walking (outdoor)** workout before the session.
2. After the session: workout history → this walk → read **duration, distance, avg pace, avg HR**.
3. If the watch shows time-in-zone, grab that too.

## Targets

| Metric | Target | Why |
| ------ | ------ | --- |
| Minutes | Tue/Thu 40–50 · Sat ~55–65 | Dose control at 119 kg |
| Avg HR | **105–130 typical, cap 130** | Fat oxidation + heart health, joint-safe |
| Standard | Brisk, talk test | No jogging in W1 |

**Above 130 avg → slow down.** Below 105 → honest data, still a valid session.
