## 2. Competitor Visual Audit

Screenshot websites, socials, packaging of your **5 closest competitors**, pin side by side, then note:

| Check | Competitor pattern observed | Opportunity |
| --- | --- | --- |
| Dominant visual style | | |
| Color clustering (everyone blue?) | | |
| Typography tendency (serif/sans) | | |
| Tone (formal/playful) | | |

> Convention vs opportunity: blending in = invisible, breaking convention = risk. Decide deliberately.

## 3. Positioning Statement (fill-in master)

```markdown
For [target audience] who [core need],
[BUILD BRAND] is the [category]
that [key differentiator].
Unlike [main alternative], we [reason to believe].
```

**Filled example**

```markdown
For freelance designers who lose hours formatting decks,
SlideKit is the presentation template studio
that ships pixel-perfect, brand-token-ready slides.
Unlike generic marketplaces, every file follows one documented design system.
```

## 5. Personality & Emotion

Pick **3–5 adjectives** total. More than 5 = no personality.

```markdown
Our brand is: [e.g. precise / warm / bold / understated / playful]

If our brand were a person, they would:
- Speak like: ____________
- Dress like: ____________
- Never be caught: ____________

Emotions we want people to feel (pick 2–3): [confidence / calm / excitement / trust / belonging / curiosity]
```

**Slider calibration** — mark where you sit between poles:

```
Playful  ●————○————● Serious
Luxury   ●——○———————— Mass
Bold     ●————————○—— Quiet
Classic  ——●————○————· Edgy
```
