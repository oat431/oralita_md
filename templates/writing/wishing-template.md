# Wishing Templates

> Fill-in masters per occasion. Copy ONE block, fill in minutes, send. Principles & register map (incl. formal/elders register per language): [[04-Wishing-Note-Guide]].
>
> **Language-neutral by design:** Address → Ground → Wish → Close works in any language. Register particles/honorifics come from the knowledge guide, not this skeleton.

## 🎂 Birthday

```markdown
**To:** <name> · **Medium:** card/LINE/post

Happy birthday, <name>!

<GROUND: one specific thing about THEIR year — survived, built, learned, endured>

This year I'm wishing you <ONE concrete hope tied to their actual goal> —
you've earned <the thing that makes it plausible>.

<close scaled to closeness>
```

For elders/formal recipients: add the honorific register + stacked blessings appropriate to the culture — see the register map in [[04-Wishing-Note-Guide]].

**Filled example**

```markdown
Happy birthday, Mint!

You somehow shipped the migration AND kept the team sane during the
audit — I still don't know how you did both.

This year I hope the portfolio project finally gets the users it
deserves. You've earned a win that's yours alone.

Go celebrate properly. 🎂
```

## 🎓 Graduation

```markdown
Congratulations, <name>! 🎓

Everyone saw the gown. I saw <the hard stretch nobody else witnessed>.

Next chapter's lucky to get you. When <their stated next step> starts
feeling impossible — and it will for a week or two — remember <specific
proof they handle hard things>.
```

## 💼 New job / promotion

```markdown
Congrats on <role>! Nobody who watched you <specific skill/moment>
will be surprised. Go find out what that team's real problem is —
then do the thing you do.
```

## 👋 Farewell / project end

```markdown
<Name>, before you go —

Working with you meant <one true specific moment of the work together>.
That's the part I'm keeping.

<Their next step> is getting someone good. Don't be a stranger —
I'm expecting the "guess what my new team did" messages.
```

## 🕯️ Condolence (⚠️ acknowledge, never explain away)

```markdown
Dear <name>,

I was so sorry to hear about <loss>. <One honest sentence about the
person — a quality, a memory. Say the loss is real; don't soften it
into nothing.>

No need to reply to this. I'm bringing food over <specific day> —
tell me if another day is better.

With love,
<yours>
```

> ⚠️ Universal law, every language: **no "at least…", no silver linings, no "time heals"** — those erase the grief. Ground honestly, offer something concrete on a specific day.

## Length targets (all occasions)

| Medium | Size |
|--------|------|
| Chat/LINE | 1–3 lines |
| Card | 2–4 sentences |
| Speech/toast | 30–60 sec (~80–150 words spoken) |
| Social post | 1–2 lines — the photo carries it |
