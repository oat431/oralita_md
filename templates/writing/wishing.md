# Wishing Templates

> Fill-in masters per occasion. Copy ONE block, fill in minutes, send. Principles & register map: [[04-Wishing-Note-Guide]].

## 🎂 Birthday — EN

```markdown
**To:** <name> · **Medium:** card/LINE/post

Happy birthday, <name>!

<GROUND: one specific thing about THEIR year — survived, built, learned, endured>

This year I'm wishing you <ONE concrete hope tied to their actual goal> —
you've earned <the thing that makes it plausible>.

<close scaled to closeness>
```

**Filled example**

```markdown
Happy birthday, Mint!

You somehow shipped the migration AND kept the team sane during the
audit — I still don't know how you did both.

This year I hope the portfolio project finally gets the users it
deserves. You've earned a win that's yours alone.

Go celebrate properly. 🎂
```

## 🎂 Birthday — TH

```markdown
**ถึง:** <ชื่อ> · **ช่องทาง:** การ์ด/LINE/โพสต์

สุขสันต์วันเกิดนะ <ชื่อ>!

<GROUND: เรื่องเฉพาะเจาะจงจากปีของ "เขา" — รอดมาได้ ทำได้ เรียนรู้ ฝ่าฟัน>

ปีนี้ขอให้ <ความหวังที่รูปธรรม 1 อย่าง ผูกกับเป้าหมายจริงของเขา> —
เพราะสิ่งที่เขาทำมาทั้งปี <เหตุผลที่เชื่อได้ว่าขอแล้วถึงเหมาะ>

<ปิดท้ายตามระดับความสนิท — เพื่อนแนบเบา ผู้ใหญ่ใส่ นะ/ครับ/ค่ะ>
```

## 🎂 Birthday — elders / formal (TH)

```markdown
สุขสันต์วันคล้ายวันประสูติ <ครับ/ค่ะ> <คุณลุง/คุณป้า/อาจารย์...>

<GROUND: เกรงใจ + ความหมายที่ท่านมีให้ — ขอบคุณสิ่งที่ท่านเคยให้โดยเฉพาะ>

ขออวยพรให้ <ท่าน> จึง <สุขภาพแข็งแรง และอีก 1–2 คำพรที่เฉพาะกับตัวท่าน>
<ปิดด้วย นะครับ/นะค่ะ>
```

## 🎓 Graduation — EN

```markdown
Congratulations, <name>! 🎓

Everyone saw the gown. I saw <the hard stretch nobody else witnessed>.

Next chapter's lucky to get you. When <their stated next step> starts
feeling impossible — and it will for a week or two — remember <specific
proof they handle hard things>.
```

## 🎓 จบการศึกษา — TH

```markdown
ยินดีด้วยนะ <ชื่อ>! 🎓

คนอื่นเห็นแค่ชุดครุย แต่ฉัน(ผม)เห็น <ช่วงที่ลำบากซึ่งไม่มีใครเห็น>

บทต่อไปโชคดีที่ได้เธอไป ถ้า <ก้าวถัดไปที่เธอบอกไว้> มันดูเป็นไปไม่ได้
สักช่วง — ซึ่งจะเป็นแบบนั้นสักอาทิตย์สองอาทิตย์ — ก็จำไว้ว่า
<หลักฐานว่าเธอเคยผ่านอะไรแบบนี้มาแล้ว>
```

## 💼 New job / promotion — EN + TH pair

```markdown
EN:
Congrats on <role>! Nobody who watched you <specific skill/moment>
will be surprised. Go find out what that team's real problem is —
then do the thing you do.

TH:
ยินดีด้วยกับตำแหน่งใหม่! คนที่เคยเห็น <ฝีมือ/ช่วงเวลาเฉพาะ> ของเธอ
ไม่มีใครแปลกใจ ไปหาเถอะว่าปัญหาจริง ๆ ของทีมนั้นคืออะไร
แล้วก็ทำสิ่งที่เธอถนัด
```

## 👋 Farewell / project end — EN

```markdown
<Name>, before you go —

Working with you meant <one true specific moment of the work together>.
That's the part I'm keeping.

<Their next step> is getting someone good. Don't be a stranger —
I'm expecting the "guess what my new team did" messages.
```

## 👋 ลาก่อน / ปิดโปรเจกต์ — TH

```markdown
<ชื่อ> ก่อนไปนะ —

ได้ทำงานด้วยแล้วมันคือ <ช่วงเวลาจริงเฉพาะเจาะจงหนึ่งช่วงของงานร่วมกัน>
ตรงนั้นแหละที่จะจำไปนาน

<ก้าวต่อไปของเขา> ได้คนดีไป อย่าหายกันนะ รอ message
"รู้เรื่องทีมใหม่ผม/ฉันมั้ยล่ะ" จากเขาอยู่
```

## 🕯️ Condolence — EN (⚠️ acknowledge, never explain away)

```markdown
Dear <name>,

I was so sorry to hear about <loss>. <One honest sentence about the
person — a quality, a memory. Say the loss is real; don't soften it
into nothing.>

No need to reply to this. I'm bringing food over <specific day> —
tell me if another day is better.

With love,
<yours>
```

## 🕯️ แสดงความอาลัย — TH

```markdown
เขียนถึง <ชื่อ>:

ขอแสดงความอาลัยกับเรื่องของ <ผู้เสีย> นะครับ/ค่ะ
<ประโยคตรง ๆ หนึ่งประโยคเกี่ยวกับคนดี ๆ ของเขา — ยอมรับว่ามันเจ็บ อย่าปลอบจนกลายเป็นแก้ต่าง>

ไม่ต้องตอบก็ได้นะ พฤหัสนี้จะหาอาหารไปส่งที่บ้าน —
ถ้าวันไหนสะดวกกว่า บอกได้เลย

ด้วยความห่วงใย,
<ชื่อเรา>
```

> ⚠️ Both languages, same law: **no "at least…", no silver linings, no "time heals"** — those erase the grief. Ground honestly, offer something concrete on a specific day.

## Length targets (all occasions)

| Medium | Size |
|--------|------|
| LINE/chat | 1–3 lines |
| Card | 2–4 sentences |
| Speech/toast | 30–60 sec (~80–150 words spoken) |
| Social post | 1–2 lines — the photo carries it |
